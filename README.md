# Student Report Al-Karim Mobile

Student daily report for parents and teachers monitoring for Sekolah Alam Al-Karim.

## Overview

This mobile application is designed to help parents and teachers at Sekolah Alam Al-Karim monitor student daily activities and reports efficiently. Built using Kotlin, the app aims to simplify communication and progress tracking between school and home.

## Features

- View daily student reports
- Teacher input for academic and behavioral observations
- Parent access to student progress
- Secure login for parents and teachers
- Easy navigation and user-friendly interface

## Technologies Used

- **Kotlin** (100%)

## Getting Started

### Prerequisites

- Android device or emulator
- Android Studio (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ichwansh03/student-report-alkarim-mobile.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on your device or emulator.

## Usage

- Teachers log in to input daily reports.
- Parents log in to view reports and monitor progress.
- All data is securely managed and accessible only to authorized users.
